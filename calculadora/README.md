# Calculadora Web

Projeto de uma calculadora desenvolvida com HTML, CSS e JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

✅ Soma  
✅ Subtração  
✅ Multiplicação  
✅ Divisão  
✅ Histórico de cálculos  
✅ Histórico salvo no navegador  
✅ Modo escuro  
✅ Copiar resultado  
✅ Limpar histórico  

## Objetivo

Praticar lógica de programação, manipulação do DOM e armazenamento de dados utilizando JavaScript.
